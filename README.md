# Jogos

Dois jogos feitos só com HTML, sem servidor nem banco de dados.

Site: https://zikkuratlights.github.io/Jogos/

- `index.html`: página inicial com os dois jogos
- `repertorio.html`: Repertório, quiz de conhecimentos gerais (216 fichas, 9 classes, 3 níveis)
- `abajur.html`: Abajur, brincadeiras lentas para a hora de dormir

## Publicação

O site é publicado pelo GitHub Pages a partir da branch `main`, pasta `/ (root)` (Settings → Pages). O arquivo `.nojekyll` faz o GitHub publicar os arquivos como estão, sem processá-los.

## Como atualizar um jogo

Clique em **Add file → Upload files**, envie o arquivo novo com o mesmo nome (por exemplo, `repertorio.html`) e confirme em **Commit changes**. O site se atualiza sozinho em alguns minutos.

O progresso de cada pessoa fica salvo no navegador dela (localStorage). Nada é enviado para servidor nenhum.
